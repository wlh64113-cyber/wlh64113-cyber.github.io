## 为什么搭这个网站

我希望这里不仅是一个博客，还能逐渐变成自己的技术知识库：

- 系统化学习一门技术
- 记录学习路径与完成进度
- 整理长期文章与项目复盘
- 把零散笔记沉淀为可检索的知识

## 当前技术栈

- Git / GitHub
- GitHub Pages
- Astro
- Markdown

后续文章只需要在 `src/content/articles/` 新建 Markdown 文件，就会自动进入文章系统。
