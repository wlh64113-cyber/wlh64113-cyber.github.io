这是 **Blog of Even** 的第一篇正式文章。

## 为什么搭这个网站

我希望这里不仅是一个博客，还能逐渐变成自己的技术知识库：

- 系统化学习一门技术
- 记录学习路径与完成进度
- 整理长期文章与项目复盘
- 把零散笔记沉淀为可检索的知识

## 当前技术栈

- Git / GitHub
- GitHub Pages
- Hexo
- Butterfly
- Markdown

## 为什么迁移到 Hexo + Butterfly

第一版网站使用 Astro 自己实现文章、归档、标签、搜索与侧栏。随着博客功能逐渐增加，维护成本也越来越高。

现在改用 **Hexo + Butterfly** 作为博客基础设施，把成熟的博客能力交给主题本身：

- 文章归档、分类与标签
- 本地搜索
- 深色模式
- 文章目录与阅读进度
- 代码高亮、复制与折叠
- 响应式双栏布局

Blog of Even 自己继续维护的部分则是内容、学习系统和个性化视觉。

后续新增技术文章，只需要在 `source/_posts/` 中创建 Markdown 文件即可。
